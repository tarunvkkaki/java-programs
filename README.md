# Java Practice Workspace

This repository contains a small Java practice project focused on learning core Java concepts and basic programming exercises.

## Project Structure

- `java-practise/` - Java files for practice exercises
  - `Main.java` - entry point of the program
  - `Lcm.java` - class containing the LCM logic

## Run the project

Open a terminal in the workspace root and run:

```bash
cd java-practise
javac Main.java Lcm.java
java Main
```

## Example output

```text
12
```

This program calculates the least common multiple (LCM) of `4` and `6`, which is `12`.

## Purpose

The goal of this project is to practice:

- Java class creation
- method calls between classes
- object-oriented programming basics
- compiling and running Java programs from the terminal
